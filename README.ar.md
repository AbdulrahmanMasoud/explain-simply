# Explain Simply: مهارة ذكاء اصطناعي تشرح أي موضوع بلغة بسيطة

[English](README.md)

**Explain Simply** مهارة مجانية بصيغة [Agent Skills](https://agentskills.io) تجعل مساعدات الذكاء
الاصطناعي تشرح الأمور المعقدة بلغة يومية بسيطة. بدل المصطلحات الصعبة، تحصل على تشبيه واحد من
الحياة اليومية، وجمل قصيرة، وأرقامك الحقيقية، و"العيب" بكل صراحة. مثل "اشرحها لي كأني طفل"، لكن
مكتوبة للكبار.

المهارة **لأي شخص**، وليست للمبرمجين فقط: مدير يقرأ رسالة من المبرمج، أو شخص يقارن بين قرضين من
البنك، أو طالب، أو مبرمج يحاول فهم قاعدة بيانات. تعمل في **Claude** (التطبيق وclaude.ai وClaude
Code)، وفي أدوات أخرى تدعم Agent Skills مثل **ChatGPT وCodex وCursor وGitHub Copilot وGemini CLI**.

**تدعم العربية:** إذا كتبت بالعربية، تشرح لك بالعامية المصرية البسيطة، وتترك المصطلحات التقنية
بالإنجليزية.

---

## مثال: قبل وبعد

سأل مبرمج: لماذا تحتاج قاعدة البيانات إلى "index"؟ الإجابة الأولى كانت صحيحة، لكنها مليئة
بالمصطلحات التقنية، فرد: *"لسه مش فاهم، بسّطها."* وهذه الإجابة التي نجحت:

> **جدول الطلبات مثل غرفة كبيرة مليئة بالملفات.** كل طلب ملف كبير، ونحن نحتاج فقط 6 معلومات صغيرة
> من كل ملف.
>
> **بدون الـ index:** قاعدة البيانات تمر على كل ملف وتفتحه. 2 مليون ملف في كل مرة. لذلك استغرق
> الأمر من **8 إلى 90 ثانية**.
>
> **مع الـ index:** تقرأ **دفترًا صغيرًا** فيه الـ 6 معلومات جاهزة. **أقل من ثانية.**

[المثال كامل (بالإنجليزية)](examples/1-database-index.md)

## كيف تشرح المهارة؟

كل شرح له نفس الأجزاء السبعة:

1. **تشبيه واحد من الحياة اليومية**، ويبقى نفس التشبيه حتى النهاية.
2. **ما يهم فعلًا**: لب المشكلة في سطر أو سطرين.
3. **بدونه**: ماذا يحدث الآن، بالأرقام الحقيقية.
4. **معه**: ماذا يتغير، بالأرقام ومثال صغير.
5. **لماذا يهمك أنت**: فلوسك، عملاؤك، وقتك.
6. **العيب**: التكلفة أو المخاطرة، بدون مبالغة في المدح.
7. **الإجابة في سطر واحد**: "يبقى نعملها."

وتستخدم جملًا قصيرة وكلمات يومية، وتعتمد على أرقامك أنت ولا تخترع أرقامًا. وإذا لم تفهم، تجرب
تشبيهًا مختلفًا بدل إضافة تفاصيل أكثر.

## التثبيت

### في تطبيق Claude أو على claude.ai (بدون برمجة)

1. افتح **Settings > Capabilities** وفعّل **Code execution and file creation**. المهارات تحتاجه.
2. ادخل على **Customize > Plugins** واضغط **Add > Add marketplace**.
3. اكتب `AbdulrahmanMasoud/explain-simply`.
4. افتح **Explain Simply** من القائمة واضغط **Add**.

تُحفظ في حسابك، فتعمل أيضًا في Cowork وفي Claude Code عند تسجيل دخولك هناك، وتصلك التحديثات
تلقائيًا.

### في Claude Code

اكتب هذا الأمر داخل Claude Code:

</div>

```
/plugin install explain-simply --marketplace AbdulrahmanMasoud/explain-simply
```

<div dir="rtl">

### في أدوات أخرى (ChatGPT وCodex وCursor وGitHub Copilot وGemini CLI)

</div>

```bash
npx skills add AbdulrahmanMasoud/explain-simply
```

## طريقة الاستخدام

اكتب بشكل عادي، وتعمل المهارة تلقائيًا عندما تقول مثلًا:

- "مش فاهم، ممكن تبسطها؟"
- "اشرحها لي كأني مش تقني."
- "ليه محتاجين ده؟"
- "يعني إيه two-factor authentication؟"
- "المبرمج بيقول كذا، يعني إيه؟ وهل يستاهل؟"

ويمكنك في Claude Code استدعاؤها مباشرة: `/explain-simply:explain-simply ليه محتاجين CDN`

**نصيحة:** اكتب أرقامك الحقيقية، مثل مبلغ القرض أو وقت تحميل الموقع أو قيمة الفاتورة. الشرح
سيستخدمها ويصبح أوضح بكثير.

## أسئلة شائعة

### هل المهارة مجانية؟

نعم. نزّلها واستخدمها وعدّلها لنفسك أو لفريقك.

### هل هي للمبرمجين فقط؟

لا. تصلح لأي موضوع صعب: التكنولوجيا، والفلوس، والعقود، والصحة، والعلوم، وقرارات العمل. ثلاثة من
الأمثلة الأربعة ليست عن البرمجة.

### هل تعطي نصائح مالية أو طبية أو قانونية؟

تشرح الفكرة بوضوح، لكنها لا تأخذ القرار الشخصي نيابة عنك ولا تعطي تشخيصًا. وتقول لك مَن تسأل،
مثل الطبيب أو المحامي أو البنك.

### كيف أضيف تشبيهات من مجالي؟

انسخ المستودع (Fork)، وافتح ملف [`skills/explain-simply/SKILL.md`](skills/explain-simply/SKILL.md) في أي محرر نصوص، وأضف صفوفًا إلى جدول
**Choosing the picture**.
